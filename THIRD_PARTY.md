# Third-party components

- YuNet face detection model: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet — model license bundled as models/LICENSE-YuNet.txt.
- OpenCV: https://opencv.org/license/ — Apache 2.0.
- Python: https://docs.python.org/3/license.html — PSF license.
- MSS: https://github.com/BoboTiG/python-mss — MIT.
- Pillow: https://github.com/python-pillow/Pillow — HPND.
- pywin32: https://github.com/mhammond/pywin32 — PSF.
- pystray: https://github.com/moses-palmer/pystray — LGPLv3. Installed source and license remain available in the development virtual environment; upstream source can be obtained at the linked repository. PyInstaller archives can be extracted/rebuilt to replace the library.
- NumPy: https://numpy.org/doc/stable/license.html — BSD.
- PyInstaller: https://pyinstaller.org/en/stable/license.html — GPL with distribution exception.

Development-only detection fixture: NASA astronaut Eileen Collins image from scikit-image v0.22.0, https://github.com/scikit-image/scikit-image/blob/v0.22.0/skimage/data/astronaut.png (NASA public domain). It is not included in the application distribution.

Windows keyboard hook behavior: https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc. Fallback uses the built-in Win+Shift+S shortcut; no Print Screen registry setting is changed.
